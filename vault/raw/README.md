# raw/ — captura sin editar

Acá cae todo lo que entra al sistema antes de procesarse: notas de voz
transcritas, links para leer después, datos crudos de métricas, ideas sueltas.

Convención: un archivo por captura, con fecha en el nombre cuando aplique
(ej. `2026-08-19-idea-carrusel-obras.md`). La skill `vault` se encarga de
mover lo que madura a `wiki/`.
