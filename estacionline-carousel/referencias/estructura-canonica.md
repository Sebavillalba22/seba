# Estructura canónica de 8 placas

1. **Portada** — foto a sangre, título 3 renglones máx, bajada con lo accionable
2. **Cita** — la frase más fuerte, atribuida
3. **Número grande** — el dato que ancla, contextualizado y atribuido
4. **Foto enmarcada** — con crédito
5. **Lista** — 3 a 6 ítems numerados
6. **Filas** — etiqueta → valor, 3 a 4
7. **Texto** — el contexto o la letra chica
8. **Cierre** — afirmativo, con el dato que le queda al lector + CTA

## Variantes según el material

- **Sin dato numérico** → se saltea la 3 y se reemplaza por texto o cita.
- **Sin citas textuales** (partes que parafrasean) → no forzar comillas: usar
  placa de texto o atribuir a la institución, no a la persona.
- **Una sola foto** → el resto se apoya en el sistema tipográfico.
- **Dos fotos de la misma toma** → usar una sola; el hueco se llena con contenido.
- **Video vertical de celular** → placa partida.
- **Video 4:5** → marco centrado.
- **Alerta breaking** → 4 placas: portada, qué pasó, foto, recomendación.

## Alternancia
No poner dos placas del mismo tipo seguidas. Intercalar lista / filas / texto /
cita para que el deslizado no se haga plano.
