# Copy (Instagram caption) reference

When the user says "copy", "vamos al copy", "dame un copy", or similar, generate the Instagram caption to accompany the carousel.

## Default structure

```
[Optional emoji] **[Hook line — main news beat in bold]**

[1-2 paragraphs with the main facts. Use real names, ages, places. Quote directly from the source article.]

["Quote textual, entre comillas", expresó/dijo/señaló [Nombre Apellido].]

[Optional: extra context paragraph with secondary details.]

Más información en estacionline.com

#Cinco #Hashtags #Exactos #InCamelCase #SinAcentos
```

## Rules

- **Bold the lead** with `**` for Instagram emphasis
- **Real names always** — first name + surname, not just one
- **Quote directly** from the source article, in quotes
- **No invention** — every fact must be in the source
- **Length**: ~500-800 characters of body text, then hashtags
- **Close with**: exactly "Más información en estacionline.com" (rule from SKILL.md; it wins over any older example)
- **Hashtags**: **exactly 5** (rule from SKILL.md), chosen among:
  - Geographic: #Rosario #SantaFe #SanLorenzo
  - Topic: #Política #Educación #Salud (whatever applies)
  - Names of protagonists if they have public profiles
  - #Estacionline only if it's a recurring brand hashtag

## Three tonal modes — offer when uncertain

If the angle isn't clear, propose three options to the user:

**A) Institucional / informativo** — neutral newsroom voice, lead with facts, quotes follow

**B) Corto y con gancho** — hook first, sparse, momentum-driven, hashtag-heavy

**C) Protagonista** — start with a quote from the main person, build around them

> 🏠 **53 familias del departamento San Lorenzo recibieron su escritura**

>
> "Cada escritura representa tranquilidad y seguridad para una familia", expresó Di Stefano.
>
> Se entregaron 40 escrituras del Fonavi y 13 del programa de Regularización Dominial.
>

>
